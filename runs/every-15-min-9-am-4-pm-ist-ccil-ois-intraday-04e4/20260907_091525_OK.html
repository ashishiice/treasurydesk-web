## Saved URL
https://www.ccilindia.com/rupee-derivatives-dealing-system-astroid-

## What It Does
- Polls the CCIL ASTROID MIBOR OIS table every **15 minutes**.
- Records each fetch as one timestamped row in a single Excel workbook.
- One persistent worksheet only: `CCIL_OIS`.
- Each row contains the **Weighted Average Rate (WAR %)** and **Traded Notional Amount (₹ Cr)** for every tenor.

## Master Workbook Policy
Use `ccil-ois-all.xlsx` for all days. Do not create date-wise workbooks or date-wise sheets unless the user explicitly asks for a new export layout. If the same timestamp is fetched again, replace that row instead of duplicating it.

See `references/ccil-ois-master-workbook.md` for the exact workbook path, sheet, column contract, cron/script ownership, and verification checklist.

## Output Location
```
~/workspace/treasury-data/ccil-ois/
└── ccil-ois-all.xlsx
    ├── Sheet: CCIL_OIS      (15-min intraday snapshots — WAR + Vol only)
    └── Sheet: CCIL_OIS_EOD  (official daily EOD — full CCIL table, all columns)
```

## Intraday Sheet (CCIL_OIS)
| Timestamp | OIS1M_WAR | OIS1M_Vol | OIS2M_WAR | OIS2M_Vol | ... | OIS10Y_WAR | OIS10Y_Vol |

If a tenor has no trade in a given fetch, the cell is left blank rather than carrying stale data.

## EOD Sheet (CCIL_OIS_EOD)
One row per trading day. Captures the full CCIL ASTROID "Market Session Closed" table with all official columns per tenor:
| Date | OIS1M_PrevClose | OIS1M_Open | OIS1M_High | OIS1M_Low | OIS1M_LTR | OIS1M_LTA | OIS1M_LTT | OIS1M_WAR | OIS1M_NoOfTrades | OIS1M_TradedNotional | ... (repeated for all 12 tenors) |

EOD fetch runs at 17:15 IST after market close. The 5PM summary at 17:20 IST uses this sheet for official OHLC/WAR/close and the intraday sheet for volatility (max-min snapshot spread).

## CCIL Page Reference
See `references/ccil-astroid-page.md` for the saved URL, table columns, and sample data layout.

## Reusable Template
`templates/fetch_market_data.py` is a generic Playwright-to-Excel dumper for any public market-data table. Copy it, change `URL`, `TENORS`, and the parse logic, and you have a new 15-minute dump in minutes.

## Scripts
- Shared direct-API client (portlet-id scraping + POST): `~/workspace/treasury-data/ccil-ois/scripts/ccil_api.py`
- Intraday fetch + append: `~/workspace/treasury-data/ccil-ois/scripts/fetch_ccil_ois.py`
- EOD fetch (official close): `~/workspace/treasury-data/ccil-ois/scripts/fetch_ccil_ois_eod.py`
- Monitor state line: `~/workspace/treasury-data/ccil-ois/scripts/ois_state_line.py`
- 5PM summary (reads both sheets): `~/.hermes/scripts/ccil_ois_5pm_summary.py`
- Can be run manually or from cron jobs.

## Data Path (since 2026-09-04 — direct API, no browser)
The CCIL page loads its market-watch table via a Liferay AJAX POST; Playwright
`networkidle` now times out and is retired. Both fetchers use
`scripts/ccil_api.py`: GET page → scrape `p_p_id=AstroidMarketWatch_..._INSTANCE_xxxx`
(self-heals on republish) → POST resource-phase endpoint → parse `result1` JSON.
If fetching fails, first check whether the portlet id regex still matches the page.

A 200/valid-JSON response with `result1: []` can also mean the ASTROID session table
is not initialized yet right at 09:00 open (seen Mon 2026-09-07 09:00, self-recovered
by 09:07) — that is transient init lag, not a page restructure. The 15-min watch
script (`~/.hermes/scripts/ccil_ois_15min_watch.sh`) retries once after 45s on any
fetch failure; real breaks still fail twice and alert.

## Cron
Two Hermes cron jobs:
1. `ccil-ois-15min-dump` — every 15 min, weekdays, 09:00–16:45 IST. Writes to `CCIL_OIS` sheet.
2. `ccil-ois-eod-fetch` — 17:15 IST weekdays. Fetches the official CCIL "Market Session Closed" table. Writes to `CCIL_OIS_EOD` sheet.
3. `ccil-ois-5pm-summary` — 17:20 IST weekdays. Reads both sheets, outputs formatted day-end summary with official OHLC/WAR + intraday volatility.
