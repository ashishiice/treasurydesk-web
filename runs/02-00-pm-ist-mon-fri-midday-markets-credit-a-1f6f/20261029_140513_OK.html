### 1. INDIA MARKETS — Multi-Source Strategy

**Nifty 50 / Indices — NSE `allIndices` API (Primary, Official NSE Data)**
- Endpoint: `https://www.nseindia.com/api/allIndices`
- Returns: Official NSE OHLC + `previousClose` + `percentChange` + `pe`/`pb`/`dy` + `advances`/`declines` for NIFTY 50 and all sector indices in one call.
- **How to fetch**: `urllib.request` with `"User-Agent": "Mozilla/5.0"` and `"Accept": "application/json"`. No referer required.
- **Verified**: Produces exact NSE closing figures (e.g., 02-Jun-2026: O=23,229.15 H=23,556.95 L=23,229.15 C=23,483.55 Chg=+0.43%).
- **Why prefer over Yahoo**: Yahoo Finance v8 can have minor drift/cache lag vs official NSE close. Use NSE API for the India-equity anchor.

**Nifty 50 / Indices — Yahoo Finance v8 API (Secondary / Global Cross-Check)**
- Python endpoint: `https://query1.finance.yahoo.com/v8/finance/chart/^NSEI?interval=1d&range=5d`
- Returns: Open, High, Low, Close, Change, Change % reliably in JSON. Works via `execute_code` even when browser pages are blocked.
- Batch symbols: `^NSEI`, `INR=X`, `^TNX`, `ES=F`, `YM=F`, `NQ=F`, `^GDAXI`, `^FTSE`, `BZ=F`, `GC=F`, `DX-Y.NYB`, `^VIX`.
- Fallback: Economic Times `markets/indices/nifty-50` if API rate-limited.
- Note: Check if market is CLOSED (holiday/weekend) and use last trading day.

**Sector Performance — NSE `allIndices` API**
- Endpoint: `https://www.nseindia.com/api/allIndices`
- Returns all major sector indices with OHLC + change: NIFTY BANK, NIFTY AUTO, NIFTY FMCG, NIFTY IT, NIFTY METAL, NIFTY PHARMA, NIFTY REALTY, NIFTY ENERGY, NIFTY INFRA, NIFTY MEDIA.

- **How to fetch**: `urllib.request` with standard `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)` header. Referer not required for this endpoint.
- **Treasury signal**: Always compute Bank Nifty % change minus Nifty 50 % change. A gap ≥0.5% (Bank Nifty underperforming) is a credit/rate-fear signal for NBFC/Bank positioning commentary.

- **Why include**: Bank Nifty often leads or trails broader financials and directly signals sentiment toward banks/NBFCs. For the NBFC treasury desk treasury, Bank Nifty divergence vs Nifty 50 is actionable (e.g., if Bank Nifty drops more than Nifty, credit/rate fears may be driving financials).

## Critical Pitfalls & Workarounds

> Session-specific learnings: see `references/session-notes-2026-05-04.md`, `references/session-notes-2026-06-03.md`, and `references/session-notes-2026-06-19.md` for extraction patterns observed under cron-job/WSL execution.

### 1. RBI Reference Rate Page Errors
- **Problem**: `ReferenceRateDisplay.aspx` is permanently unavailable (returns 404). `ReferenceRateArchive.aspx` can be reached through browser navigation, but the target-date rate may still be unpublished; in the 19-Jun-2026 run it returned `No Reference Rate Found` for `19/06/2026` while showing the 18-Jun-2026 USD rate of `94.2795`. The RBI homepage `home.aspx` "Exchange Rates" accordion loads client-side AJAX that does **not** appear in the initial HTML and is **not** reliably rendered in browser snapshots or accessible DOM even after clicking the accordion.
- **Solution** (in order of reliability):
  1. **RBI-verified reference rate** — use `ReferenceRateArchive.aspx` via browser navigation and submit the date/currency filters. If it returns `No Reference Rate Found`, do not infer the rate from the homepage footer or market spot.
  2. **Market spot for same-day EOD** — use CCIL USD/INR SPOT LTR/range or Yahoo `USDINR=X` as a proxy, clearly labelled as market spot.
  3. **Report gap explicitly** — write: "RBI reference rate for [date] unavailable; latest RBI-verified reference rate was [date]: [rate]. Market spot was [rate]."

### 2. Stale FBIL MIBOR-OIS Data

- **Problem**: FBIL `wasdm/miborois/fetch` can return data, but the latest process run date may be several business days old.
- **Pitfall**: Do not treat stale FBIL MIBOR-OIS data as the current day's O/N OIS fixing.
- **Solution**: Check `processRunDate` and `displayTime` in every FBIL response. If stale, report O/N OIS as unavailable and include current CCIL OIS tenors only as context.

### 3. Market Holidays
- **Check**: Always verify if today is a market holiday (Eid, Holi, Diwali, Ambedkar Jayanti, etc.)
- **Handling**: Use last trading day's closing data and note "Markets closed for [holiday]"
- **Next Session**: Note the next trading date for overnight positioning
- **Sunday gap in RBI Money Market data**: RBI Money Market Operations as on Sunday show zero overnight volumes (Call Money, Triparty Repo, Market Repo all 0.00). This is expected due to market closure. Fall back to the most recent Friday/Saturday data and explicitly label the date.

### 3. Money Market Data Timing
- **Weekends/Holidays**: RBI Money Market Operations PDF shows zero volume
- **Solution**: Use last trading day's data and explicitly note the date
- **Call Money Range**: Format as "X.XX% – X.XX% (last trading date: DD MMM)"

### 4. G-Sec Yield Estimates
- **Problem**: No real-time public G-Sec yield ticker
- **Solution**: Use Economic Times bonds section news for trend + estimate range
- **Note**: "Estimated ~X.XX% – X.XX% based on market sources"

### 5. FII/DII Data Timing
- **Provisional vs Final**: ET shows "provisional" for current day
- **30-day trends**: More important than single day for treasury positioning
- **Context**: Always compare FII outflows vs DII absorption capacity

### 6. Bot Detection Avoidance (Environment: WSL / Cloud Browser)
- ✅ **PRIMARY API — Yahoo Finance v8**: Use `https://query1.finance.yahoo.com/v8/finance/chart/{SYMBOL}?interval=1d&range=5d` for reliable OHLC + change. Works with requests/execute_code even when browser fails.

## T-Bill Auction Calendar Pattern

RBI conducts T-bill auctions on **Wednesdays**:
- **91-day T-bills**: ₹9,000-15,000 Cr (most liquid, benchmark for short-term funding)
- **182-day T-bills**: ₹6,000-8,000 Cr  
- **364-day T-bills**: ₹6,000-7,000 Cr

**Settlement**: T+1 (Thursday following Wednesday auction)

**Quarterly calendar resets (July–September pattern, verified July 2026):**
- The *Calendar for Auction of Government of India Treasury Bills* release often changes the weekly mix while keeping the weekly total close to ₹24,000 Cr.
- Example Q2 FY27: 91D ₹9,000 Cr + 182D ₹8,000 Cr + 364D ₹7,000 Cr = ₹24,000 Cr.
- When the mix shifts, analyze **which tenor's supply is being increased/decreased** rather than only the headline total — it signals RBI's duration-management intent.

## Critical Data Points to Extract

For EACH tenor (91D, 182D, 364D), capture:
```
1. Notified Amount (₹ Cr) - RBI's target borrowing
2. Bids Received (Number + Amount) - total demand
3. Cut-off Price / Yield - winning bid
4. Yield to Maturity (YTM%) - annualized
5. Bids Accepted (Number + Amount) - RBI's take-up
6. Partial Allotment % - % accepted at cut-off rate
7. Weighted Average Yield (WAY%) - blended cost to RBI
```

**⚠️ NIL / Devolved Auction Handling:**

Cross-check with the separate "Cut-off" press release which will state "NIL" under Total Face Value Accepted. In such cases:
- Coverage ratio still matters (shows demand relative to notified)
- WAY and cut-off are undefined
- Total borrowing shortfall must be calculated across all tenors
- This is a MAJOR market signal — see "Auction Devolvement" analysis section below

## Analysis Framework

### 1. Auction Size Analysis

```

- Increasing total weekly size → Larger Centre borrowing / liquidity absorption
- Decreasing total weekly size → Tighter liquidity management
```

### 2. Bid Coverage Analysis

```
Coverage Ratio = Bids Received / Notified Amount

Example from April 8, 2026:
91D: ₹60,631.600 Cr received / ₹12,000 Cr notified = 5.05x coverage
182D: ₹19,996.400 Cr / ₹6,000 Cr = 3.33x coverage  
364D: ₹13,410.100 Cr / ₹6,000 Cr = 2.24x coverage

INTERPRETATION:
- >4x coverage = Strong demand, yields likely compress
- 2-4x coverage = Normal demand
- <2x coverage = Weak demand, yields likely widen
```

### 3. Yield Analysis

```
Current Yield (April 8, 2026 auction):
91D: 5.3064% YTM | 182D: 5.5299% YTM | 364D: 5.6278% YTM

vs Policy Rates (April 2026 MPC):
Repo: 5.25% | SDF: 5.00% | MSF: 5.50%

SPREAD ANALYSIS:
91D (5.3064%) vs Repo (5.25%) = +5.6 bps premium
364D (5.6278%) vs Repo = +37.8 bps premium (forward funding cost)

T-Bill Curve Steepness:
364D - 91D spread = 32.1 bps (normal term premium)
>40 bps = Expecting rate hikes
<20 bps = Expecting rate cuts or flat curve
```

### 4. Weighted Average vs Cut-off Spread

```
WAY - Cut-off = Auction selectivity

April 8, 2026:
91D: WAY 5.3015% - Cut-off 5.3064% = -0.5 bps (competitive bidding)
182D: 5.5088% - 5.5299% = -2.1 bps
364D: 5.6111% - 5.6278% = -1.7 bps

INTERPRETATION:
- Negative spread = RBI accepted bids below cut-off (VERY accommodative)
- Small positive spread (<1 bps) = Competitive bidding, neutral policy
- Large positive spread (>2 bps) = RBI rejected high-yield bids (hawkish)

⚠️ Negative WAY-Cut indicates surplus liquidity and RBI reluctance to reject bids
```

### 5. Partial Allotment Analysis

```
Partial Allotment % = (Number of bids accepted / Number at cut-off)

April 8, 2026:
91D: 53.9280% (6 bids) - HIGH pressure, many rejected
182D: 18.6190% (6 bids) - VERY HIGH pressure
364D: 78.5714% (2 bids) - Low pressure

INTERPRETATION:
- <25% partial allotment → Severe demand/supply imbalance
- 25-50% → Significant competition at cut-off
- >75% → Light competition, easy allotment
```

3. **Results timing pattern**: 
   - Wednesday auction → Results often post same day or next 1-2 days
   - If only announcement is visible → results may not be published yet

   - Weighted Average YTM = RBI's blended borrowing cost
   - These differ when partial allotments occur
