**What Freebuff is:** Freebuff is the free version of CodeBuff, an open-source AI coding assistant that lives in your terminal. You describe what you want in plain English and it modifies your code. The free version strips off signup walls — no subscription, no credits, no API key. Install with `npm install -g freebuff`, navigate to your project, type `freebuff`, and it runs. No account setup or config screen.

**Funding model — how it stays free:** Funded by small text ads that appear quietly in the terminal while you work. Built intentionally this way by founder James Grugget, who previously ran Manifold (a large consumer app). Nearly 200,000 developers have joined. The ad model means prompts may be examined to serve relevant ads — but uploaded files and connected repos are not handed to advertisers. Worth understanding before leaning on it for sensitive work.

**Multi-agent architecture (the key differentiator):** Unlike most AI coding tools that use one model for everything and guess which files matter, Freebuff runs a team of ~9 smaller agents each with one job, executed in sequence: (1) a file-picker agent scans your whole project in ~2 seconds to identify relevant files; (2) a planner agent maps out the changes and their order; (3) an editor agent makes precise edits (not full rewrites); (4) a reviewer agent double-checks before handing back. Additional agents can research the web and use a browser. The maker's own tests claim it edited code more accurately than Claude Code — though Goldie caveat: those are their own tests, verify yourself.

**Speed and context handling:** Because it gathers context in seconds rather than slowly crawling files, it starts 5–10x faster than the tool everyone compares it to. A fast model scans a project map, picks the ~dozen relevant files, and summarizes them. Long sessions don't break it — when idle for a few minutes, it quietly summarizes everything to that point without dropping key details, so you can keep going without manual context management.

**Model selection:** Not locked to one company. Full version offers Deepseek V4 Pro, Myo 2.5 Pro, Deepseek 5 Flash, Myo 2.5, Miniax M3, and newly added GPT 5.6 Luna. A smaller Gemini model handles file-finding in the background. Real current models — the same class people typically pay for elsewhere.

**Five products, all free:** (1) CLI terminal tool (the main one); (2) Desktop app in beta — run multiple coding agents simultaneously, each in its own workspace; (3) Freebuff Web — a single prompt generates a full working app on a live link, no code needed; (4) Freebuff Cloud — full coding setup in your browser, works on any GitHub project without installing anything; (5) Freebuff Chat — a research-style chat that thinks deeply before answering.

**Real examples shown:** Goldie built a landing page for his "AI Profit Boardroom" — gave plain-word instructions for a clean signup page with headline, benefits, and form; Freebuff found files, made changes, and self-checked. He also used Freebuff Web to spin up a member dashboard from a single prompt, auto-deployed to a live link.

**Usability features:** `@filename` to point directly at a known-relevant file (skip hunting). `@agentname` to call a specific agent. Bash mode to run terminal commands mid-task. `/history` to jump back into past conversations. The knowledge file: running `init` creates a `knowledge.md` where you store project setup and rules — Freebuff reads it first on every task, so it stops asking repetitive questions and starts already knowing your setup.

**Geographic caveat:** Full version (all models) available in US, Canada, UK, EU, and more. Outside those or on VPN → limited mode: fewer models, six 1-hour sessions per day. Still free, still useful, but know this going in.

Goldie bets this shows up in Maps, Photos, and eventually Search itself. The shift: from "ask the robot" to "the robot already noticed." Most AI tools still require you to ask a question; Dream Beans flips that — it surfaces things before you think to look.
