## Workflow

1. **Fetch** the transcript using the helper script with `--text-only --timestamps`.
2. **Validate**: confirm the output is non-empty and in the expected language. If empty, retry without `--language` to get any available transcript. If still empty, tell the user the video likely has transcripts disabled.
3. **Chunk if needed**: if the transcript exceeds ~50K characters, split into overlapping chunks (~40K with 2K overlap) and summarize each chunk before merging. **Alternative for framework extraction**: when the goal is structured analysis (tools, use cases, pros/cons) rather than a narrative summary, use keyword-driven extraction instead of blind chunking — search the transcript for framework-relevant terms and extract ±400–800 character snippets around each hit. This reduces context consumption by 80%+ while preserving exact quotes.
4. **Transform** into the requested output format. If the user did not specify a format, default to a summary.
5. **Verify**: re-read the transformed output to check for coherence, correct timestamps, and completeness before presenting.

## Error Handling

### Common Transcript API Errors

**IP Blocking (Most Common)**: YouTube aggressively blocks cloud provider IPs. If you see errors about "automated queries" or IP blocks:
- Try using a browser-based approach if stealth browsing is available
- Consider using YT-DLP with `--write-auto-subs` instead
- Plan for transcript unavailability in automated workflows

**API Breaking Changes**: The youtube-transcript-api library changes frequently:
- **v1.x**: Must instantiate first: `api = YouTubeTranscriptApi(); transcript = api.fetch(video_id)`
- **older versions**: Could call static method: `YouTubeTranscriptApi.get_transcript(video_id)`
- Always use the helper script from this skill which maintains compatibility

### Transcript Disabled or Unavailable

- **Transcript disabled**: tell the user; suggest they check if subtitles are available on the video page
- **Private/unavailable video**: relay the error and ask the user to verify the URL
- **No matching language**: retry without `--language` to fetch any available transcript, then note the actual language to the user
- **Video too new**: Auto-generated captions may not yet be available; wait 24 hours

### Chapter-Based Content Synthesis

When transcripts are unavailable but you need content (e.g., for narrative summaries or storytelling):

1. **Extract video metadata** with yt-dlp:
   ```bash
   yt-dlp -J --skip-download "URL" | jq '{title, description, chapters, upload_date}'
   ```

2. **Parse chapters from description** or yt-dlp output — these often contain detailed section breakdowns with timestamps

3. **Synthesize narrative** from available data:
   - Chapter titles provide structural flow
   - Description often contains key points discussed
   - Product links indicate topics covered (for review/product videos)
   - View counts and upload dates give recency context

4. **Be transparent**: When synthesizing from chapters rather than transcripts, note this in output — e.g., "Based on chapter markers and video description..."

This approach works well for creating structured summaries, storytelling formats, and identifying key topics when word-for-word transcripts are unavailable.

## Fallback Approaches When Transcripts Fail

When youtube-transcript-api consistently fails (common in automated/cron contexts):

1. **YT-DLP with subtitles** (may need JS runtime):
   ```bash
   yt-dlp --write-auto-subs --skip-download --sub-langs en -o "%(id)s" "URL"
   ```

2. **Extract metadata via YT-DLP** for content synthesis:
   ```bash
   yt-dlp -J --flat-playlist --playlist-end 10 "CHANNEL_URL"
   ```
   Then use video titles, descriptions, and chapter data for summaries

3. **Browser-based extraction** (requires browser tools):
   - Navigate to YouTube video
   - Access setting menu and subtitle options
   - Look for transcript panels in the page HTML

4. **Graceful degradation**: When transcripts are unavailable but the user needs content:
   - Extract video metadata (title, description, chapter markers)
   - Use chapter titles + description to create meaningful summaries
   - Document what you couldn't access transparently

## Cron Job Considerations

When using this skill in automated cron jobs:

1. **Environment**: Cron jobs run in isolated sessions. The package may need verification/Installation at runtime.
2. **IP blocking**: YouTube aggressively blocks cloud provider IPs—transcript failure rates in automated environments can exceed 80%. **Always implement fallback logic that extracts metadata or returns [SILENT] when transcripts are unavailable.**
3. **Transcript size**: Long videos (2+ hours) can generate 100K+ character transcripts. Chunk appropriately.
4. **Rate limits**: YouTube Transcript API has no explicit limits, but batching requests is courteous.
5. **Channel monitoring**: For daily channel checks:
   - YouTube RSS feeds: `https://www.youtube.com/feeds/videos.xml?channel_id=CHANNEL_ID` (often 404s)
   - Use YT-DLP: `yt-dlp -J --flat-playlist --playlist-end 10 "https://www.youtube.com/@ChannelName/videos"`
6. **Transcript availability**: ~70% of YouTube videos have auto-generated transcripts. In automated/cron contexts, expect ~20-30% success rate due to IP blocking. Plan for graceful degradation.
