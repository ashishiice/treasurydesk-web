# TreasuryDesk — automated treasury operations for Indian NBFCs

## The Desk — Treasury Ascent (training game)

Offline Android/web game to learn, test and certify NBFC treasury roles: Back Office → Mid Office → Front Office → Treasurer.

- Web build: `game/` (open `game/index.html`; on GitHub Pages at `/game/`).
- Android: `android/` wraps the game in a WebView. The **Build The Desk APK** workflow builds a signed APK on every push to `game/**` or `android/**` and publishes it as a pre-release (`desk-v0.1.N`).
- Phase 1 (live): Back Office track — Learn/Test drills, Spot the Break, Cash Waterfall, Black Swans (The Freeze, Fat Finger), proctored certification exam, L5 certificate.
- Content status tags: VERIFIED / LIVE-VERIFY / BEST PRACTICE / GENERATED (see Settings → Content & verification log). All entities are fictional; market data is synthetic.
